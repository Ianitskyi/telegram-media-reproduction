# Дані

Сирі дані не зберігаються в git (ліміт GitHub — 100 МБ на файл). Вони лежать у **GitHub Releases** цього репозиторію.

| Файл | Розмір | Що це |
|---|---|---|
| `telegram_all_messages.json` | ~903 МБ | Повідомлення 13 Telegram-каналів (поля: id, date, text, views, forwards, channel_username, channel_name, urls) |
| `media_all_articles.json` | ~9,8 МБ | Матеріали 142 професійних медіа, зібрані з RSS (≤100 на джерело, знімок ~травень 2026) |

Походження: Google Drive-папка Олега Семенюка `data/raw` (збір: квітень–травень 2026).
Контрольні суми й опис структури додаються після перенесення.

Щоб запустити аналіз локально, файли кладуться в `data/raw/`.
