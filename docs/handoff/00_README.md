# Handoff package: article for *Communications and Communicative Technologies*

This package is intended to let a second AI assistant join the project without requiring the full ChatGPT conversation history.

## Source-of-truth principle

1. The canonical article draft is the Google Drive / DOCX source represented here by `Communications_and_Communicative_Technologies_current.docx`.
2. Empirical data and existing analysis outputs live in the shared Google Drive folders listed in `08_SOURCE_INDEX.md`.
3. Code and methodology live in the GitHub repository listed in `08_SOURCE_INDEX.md`.
4. This package is a structured synthesis of the project state, decisions, verified findings, inconsistencies, and open questions. It should not be treated as a substitute for checking the underlying data/code when making factual claims.

## Recommended order for a new assistant

Read:
1. `01_MASTER_CONTEXT.md`
2. `03_DATA_AND_METHODS.md`
3. `04_LITERATURE_AND_THEORY.md`
4. `05_ARTICLE_STATUS.md`
5. `06_OPEN_QUESTIONS_AND_NEXT_STEPS.md`
6. `07_PROMPT_FOR_SECOND_ASSISTANT.md`
7. `08_SOURCE_INDEX.md`

Use `02_RESEARCH_LOG.md` to understand why certain methodological and terminological decisions were made.

## Language and style

The article is being written in Ukrainian. The user expects precise, non-inflated academic language, clear differentiation between verified facts and inference, and primary/academic sources where possible.
