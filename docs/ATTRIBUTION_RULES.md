# Правила класифікації явної атрибуції джерела (v3.1, після аудиту ChatGPT)

**Статус:** прототип, перевірений лише на вибірці. Повний корпус **не** запускається до ручної валідації та затвердження Андрієм.
Код: `src/v3/attribution.py`, словники: `src/v3/gazetteer.py`, тести: `tests/test_attribution_v3.py` (14 тестів).
Приклади: `docs/ATTRIBUTION_EXAMPLES.md`, таблиця для позначок — `validation/attribution_examples_v2.csv`; вибірка — `validation/attribution_sample_v2.csv`.

Зміни v3 → v3.1 (аудит ChatGPT, рішення Андрія від 2026-10-24): джерело-актор відокремлено від пункту призначення посилання; новий тип `company_organization`; нові типи повідомлень і основний знаменник; правило двокрапки; дедуплікація сутностей; виправлено фрагменти назв і хибну «рекламу».

## 1. Що вважається явним джерелом

Джерело — це те, на що адміністратор **явно вказує як на походження інформації**. Згадана в новині сутність джерелом **не** є.

| Рахуємо | Не рахуємо |
|---|---|
| «…, — УП», «— Зеленський», «— монітори» (підпис через тире) | «Зеленський прибув до Парижа» |
| «Зеленський заявив / повідомив / каже / пояснив…» (+ рос.) | «СБУ затримала агента» — дієслово дії без конструкції повідомлення (⚑1) |
| «заявив міністр Х», «повідомили у Генштабі», «йдеться у матеріалі NYT» | назва організації як учасника події |
| «за даними / за словами / з посиланням на / як пише / джерело: Х» | донати, магазини, скорочувачі, реклама |
| «Генштаб: …» — двокрапка, **лише** якщо перед нею впізнаний актор (влада, медіа, політик, експерт, Telegram-канал) і ≤4 слів (⚑1) | «Российский «Альфа-Банк Украина»: в чьих интересах…» — заголовок-тема |
| гіперпосилання на медіа / офіційний сайт / соцмережу / інший канал | самопосилання каналу, його боти, «підпишись» |
| «#нампишуть», «місцеві кажуть», «в мережі з'явилося відео» | рядки-«футери» каналу (≥1% повідомлень і ≥50 разів) |
| «Повідомляють, що…» → `anonymous` | «В Волновахе … сообщают» — місце, а не джерело |

Одне повідомлення може мати кілька джерел. Однакові сутності зливаються (лишається конкретніша назва): «СБУ» + «пресслужба СБУ» → одна; «міністр Степанов» + «міністр» → одна.

## 2. Джерело-актор vs пункт призначення посилання (нове у v3.1)

Кожне повідомлення має два окремі списки:

- **`attributed_sources`** — хто є джерелом (з тексту);
- **`linked_destinations`** — куди веде посилання (домен, видавець, тип платформи, ознака «білого списку»).

| Приклад | Джерело-актор | Пункт призначення |
|---|---|---|
| «…, — The Washington Post. [Детальніше](nv.ua/…)» | The Washington Post (`foreign_media`) | nv.ua (`ua_media_site`) |
| «…, — Autoconsulting» + посилання на Телеграф | Autoconsulting (`company_organization`) | telegraf.com.ua (`ua_media_site`) |
| «…, – ОК «Південь». [Facebook](…)» | ОК «Південь» (`ua_official`) | facebook.com (`social_platform`) |
| «Детальніше: [тут](pravda.com.ua/…)» (у тексті актора немає) | Українська правда — **виведено з посилання** (`actor_inferred_from_link`) | pravda.com.ua (`ua_media_site`, WL) |

Типи платформ: `ua_media_site`, `foreign_media_site`, `russian_media_site`, `official_site` (укр.), `foreign_official_site`, `social_platform`, `telegram_channel`, `other_site`.

⚑ **Рішення 6 (нове, відкрите).** Чи вважати джерелом-актором посилання *лише* на соцмережу або «інший сайт» без актора в тексті (youtu.be, instagram.com, megogo.net, openpetition.eu)? Зараз — так (тип `social` / `other`, позначка «з посилання»). Альтернатива: рахувати їх лише як `linked_destination`, а не як атрибуцію — інакше посилання на відео чи петицію завищує частку «з джерелом».

## 3. Тип джерела (`source_type`)

| Код | Що входить | Приклади |
|---|---|---|
| `ua_media` | українські медіа; ознака `whitelist` = з «білого списку» (142 медіа) | Суспільне, УП (WL); ТСН, NV, BIHUS Info |
| `foreign_media` | закордонні медіа | Reuters, Bloomberg, NYT, La Repubblica |
| `russian_media` | російські медіа | ТАСС, Mash |
| `ua_official` | українська влада, військові, держкомпанії, посадовці (у т.ч. Верховна Рада, ОП) | Зеленський, Генштаб, Резніков, Подоляк |
| `foreign_official` | іноземні уряди, посадовці, міжнародні організації | Пентагон, Трамп, МВФ, ЦРУ |
| `russian_official` | російська влада (⚑2: окремо, зі зведенням з іноземною у звітах) | Пєсков, МИД России |
| `politician` | депутати, партії, колишні посадовці | нардеп Железняк |
| `expert` | експерти, аналітичні центри | Жданов, ISW |
| `company_organization` | компанії, фонди, громадські організації (⚑4) | ДТЕК, Yasno, Autoconsulting |
| `telegram` | інші Telegram-канали | «монітори», @handle, Беларускі Гаюн |
| `social` | соцмережі, «у мережі» | «в мережі з'явилося відео» |
| `unnamed_media` | медіа без назви | «ЗМІ», «росЗМІ», «видання» |
| `eyewitness` | очевидці, мешканці, підписники | «#нампишуть», «місцеві» |
| `anonymous` | анонімні | «джерела», «співрозмовник», «повідомляють» |
| `person_other` | названа особа, ще не класифікована — **тимчасовий кошик для перевірки**, перед аналізом нормалізується вручну (⚑3) | Олексій Громов |
| `other` | інше назване джерело | ЦОС, домени без типу |

## 4. Спосіб атрибуції і конкретність

`attribution_method`: `textual` / `hyperlink` / `both` / `none`.
`specificity`: `named` (конкретна назва/особа), `generic` (категорія або лише посада: «ЗМІ», «монітори», «міністр»), `anonymous`.

## 5. Тип повідомлення і знаменник (⚑5)

| Код | Що | В основному знаменнику? |
|---|---|---|
| `informational` | новини, коментарі, інше змістовне | так |
| `alert` | оперативне оповіщення про загрози | так (+ окремий звіт) |
| `ad` | явна реклама: «#реклама», «на правах реклами» тощо, або ≥2 різні рекламні маркери (лише наказові форми: «зареєструйся на…») | ні |
| `self_promo` | самопромо каналу («підписуйтесь», «наш Instagram») | ні |
| `technical` | порожні/дуже короткі/службові | ні |

**Основний знаменник RQ1** = `informational` + `alert`. Для порівняння звітуємо також усі повідомлення та лише `informational`.

## 6. Як працює прототип

1. Очищення: markdown-посилання → підпис + URL; рядки-футери вилучаються разом із посиланнями.
2. Шаблони: підпис через тире; «за даними / з посиланням / як пише / джерело:»; «у/в Х повідомили»; дієслово мовлення до/після назви; двокрапка (лише впізнані актори); «#нампишуть»; «в мережі з'явилося»; «повідомляють, що».
3. Назва обрізається (префікси «йдеться у матеріалі», «говорится в заявлении», «пояснив», «брифінг», хвости речень); назви >6 слів або з кінцем речення відкидаються.
4. Класифікація за порядком: білий список → безіменні медіа → анонімні → Telegram → рос. медіа → укр. медіа → закордонні медіа → рос. влада → іноземна влада → укр. влада → компанії → політики → експерти → соцмережі → очевидці.
5. Посилання → пункт призначення за доменом; якщо актора в тексті немає — актор виводиться з посилання.

## 7. Попередні цифри на вибірці (760 повідомлень; НЕ результати)

Тип: informational 667, alert 52, technical 24, ad 9, self_promo 8. З явним джерелом: 35,7% усіх; **37,4% основного знаменника** (n=719). До ручної валідації ці цифри не інтерпретуються.

## 8. Відомі обмеження

- поодинокі неточні типи й назви (видно в прикладах; збираємо на ручній валідації);
- пересилання (forward) не видно: збирач не зберігав джерело пересилання;
- точність/повнота — лише після ручної валідації.
