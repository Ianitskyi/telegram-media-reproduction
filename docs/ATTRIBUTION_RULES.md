# Правила класифікації явної атрибуції джерела (v3, проєкт на затвердження)

**Статус:** прототип. Повний корпус **не** запускається, доки Андрій не затвердить правила (пункти ⚑).
Код: `src/v3/attribution.py`, словники: `src/v3/gazetteer.py`, тести: `tests/test_attribution_v3.py`.
Приклади: `docs/ATTRIBUTION_EXAMPLES.md`, таблиця для позначок — `validation/attribution_examples_v1.csv`.

## 1. Що вважається явним джерелом

Джерело — це те, на що адміністратор **явно вказує як на походження інформації**, так що читач може зрозуміти, звідки вона.
Згадана в новині сутність джерелом **не** є.

| Рахуємо | Не рахуємо |
|---|---|
| «…, — УП», «— Зеленський», «— монітори» (підпис через тире після заголовка/речення) | «Зеленський прибув до Парижа» |
| «Зеленський заявив / повідомив / каже…», «Байден заявил» | «Українська правда святкує 25-річчя» |
| «заявив міністр Х», «повідомили у Генштабі», «в ДТЕК прокоментували» | назва організації як учасника події («СБУ затримала…») |
| «за даними / за словами / з посиланням на / як пише / джерело: Х» (+ рос.) | посилання на донати, магазини, рекламу, скорочувачі |
| гіперпосилання в тексті на медіа / офіційний сайт / соцмережу / інший Telegram-канал | посилання каналу на самого себе, свої боти, запрошення «підпишись» |
| «#нампишуть», «місцеві кажуть», «підписник повідомляє», «в мережі з'явилося відео» | підписи-«футери» каналу (рядки, що повторюються в ≥1% повідомлень) |
| «Повідомляють, що…» (безособове) → анонімне | |

Одне повідомлення може мати **кілька** джерел. Самопосилання каналу (його назва, бот, хендл) не рахуються.

⚑ **Рішення 1.** Чи рахувати «СБУ затримала…» / «Генштаб: …» без дієслова мовлення джерелом? Зараз — **ні** (це дія суб'єкта, а не атрибуція). Альтернатива — рахувати, якщо суб'єкт — офіційний орган і текст — його звіт.

## 2. Тип джерела (`source_type`)

| Код | Що входить | Приклади |
|---|---|---|
| `ua_media` | українські професійні медіа; ознака `whitelist` = з «білого списку» IMI/Карти (142 медіа) | Суспільне, УП (WL); ТСН, УНІАН, РБК-Україна, NV, Forbes Україна |
| `foreign_media` | закордонні професійні медіа | Reuters, Bloomberg, CNN, WSJ, BILD, The Guardian |
| `russian_media` | російські медіа | ТАСС, РИА, Mash, Медуза |
| `ua_official` | органи влади, військові, правоохоронні, держкомпанії, посадовці у ролі | Зеленський, Генштаб, ПС, ОВА, мер, міністр, Укренерго |
| `foreign_official` | іноземні уряди, посадовці, міжнародні організації | Білий дім, Трамп, Пентагон, НАТО, МВФ, ВООЗ |
| `russian_official` ⚑ | російська влада й посадовці (у дизайні — частина «іноземних офіційних») | Пєсков, Минобороны РФ, Кремль |
| `politician` | депутати, партійні лідери, колишні посадовці, публічні політики | нардеп Железняк, Гончаренко |
| `expert` | експерти, аналітики, науковці, аналітичні центри | експерт Жданов, ISW |
| `telegram` | інші Telegram-канали (у т.ч. узагальнено) | «монітори», @handle, DeepState |
| `social` | соцмережі, акаунти, «у мережі» | «в мережі з'явилося відео», посилання на X/Facebook |
| `unnamed_media` | медіа без назви | «— ЗМІ», «місцеві ЗМІ», «росЗМІ» |
| `eyewitness` | очевидці, мешканці, підписники, військові з місця | «#нампишуть», «місцеві кажуть» |
| `anonymous` | анонімні джерела | «джерела», «співрозмовник», «західний дипломат», «повідомляють» |
| `person_other` ⚑ | названа особа, яку словник ще не класифікував | Олексій Громов |
| `other` | інше названe джерело (компанії, установи, сайти) | ДТЕК, YouControl, інститут |

⚑ **Рішення 2.** Виділяти `russian_official` окремо чи злити з `foreign_official`? Пропоную окремо (для статті про Україну це змістовна різниця), зі зведенням у звітах.
⚑ **Рішення 3.** `person_other` — після перевірки вручну перекласифікувати найчастіших у словнику; решту лишити як «названа особа».
⚑ **Рішення 4.** ДТЕК / приватні компанії — `other` (зараз) чи окремий тип `company`?

## 3. Спосіб атрибуції (`attribution_method`) — на рівні повідомлення

`hyperlink` — лише посилання; `textual` — лише текст; `both` — і те, й інше; `none` — немає джерела.
На рівні джерела: `link` / `text` / `both` (якщо те саме медіа і назване, і з посиланням).

## 4. Конкретність (`source_specificity`)

`named` — конкретна назва/особа/організація; `generic` — категорія («ЗМІ», «монітори», «місцеві», «соцмережі», «експерти»);
`anonymous` — «джерела», «співрозмовник», «повідомляють».

## 5. Тип повідомлення (`message_type`) — ⚑ нова змінна

| Код | Що | Правило (евристика) |
|---|---|---|
| `ad` | реклама/промо | «#реклама», казино, крипта, «зареєструйся», «знижки до…» тощо |
| `alert` | оперативне оповіщення про загрози | короткий текст (<300 знаків) з ≥2 маркерами (шахед, ракета, курсом, укриття, тривога…) |
| `too_short` | <15 знаків | |
| `news_or_other` | решта (новини, коментарі, гумор) | |

⚑ **Рішення 5.** Знаменник для RQ1: (а) усі повідомлення; (б) лише `news_or_other` (без реклами й оповіщень) — **рекомендую (б) як основний, (а) — для порівняння**. Оповіщення — окремий жанр, де канал сам є «джерелом спостереження».

## 6. Як працює прототип (для перевірки)

1. Текст очищується: markdown-посилання → підпис, URL окремо; рядки-підписи каналу вилучаються разом із їхніми посиланнями.
2. Шаблони атрибуції: підпис через тире (кінець рядка або речення), «за даними / з посиланням / як пише / джерело:», «у/в Х повідомили», дієслово мовлення до/після назви (укр. і рос.), «#нампишуть», «в мережі з'явилося», «повідомляють, що».
3. Назва джерела обрізається (без «що», «в ефірі», «сьогодні»…), класифікується за порядком: «білий список» → безіменні медіа → анонімні → Telegram → російські медіа → укр. медіа → закордонні медіа → російська влада → іноземна влада → укр. влада → політики → експерти → соцмережі → очевидці.
4. Посилання класифікуються за доменом (медіа / .gov.ua / соцмережі / t.me/@канал / інше); донати, магазини, скорочувачі, власні канали — не джерело; посилання на соцмережі в самопромо («підписуйтесь на наш Instagram») — не джерело.

## 7. Відомі обмеження прототипу (на 150 прикладах)

- деякі хвости речень після тире потрапляють у назву (обрізаються не завжди);
- «жителі/очевидці» іноді ловляться в статистичних фразах («1117 жителів Львівщини»);
- поодинокі неточні типи (напр., «Зять Шойгу» → російська влада);
- пересилання (forward) не видно: збирач даних не зберігав, звідки переслано;
- оцінка точності/повноти — лише після ручної перевірки (план: `validation/CODEBOOK.md`, адаптувати під нові змінні).

## 8. Що потрібно від Андрія

1. Переглянути `docs/ATTRIBUTION_EXAMPLES.md` (або CSV) — позначити помилки.
2. Вирішити ⚑1–5.
3. Після цього: виправлення → ручна валідація (вибірка) → запуск на повному корпусі.
