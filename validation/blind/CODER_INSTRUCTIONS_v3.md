# Інструкція для незалежного кодера: явна атрибуція джерела в Telegram-повідомленнях

Ви — незалежний кодер у науковому дослідженні практик атрибуції джерел інформації в популярних українських Telegram-каналах (2020–2026). Ваше завдання — для кожного повідомлення визначити, чи дає канал читачеві зрозуміти, **звідки походить інформація**, і якщо так — які це джерела.

Працюйте **лише з текстом повідомлення**. Не шукайте оригінали, не відкривайте посилання, не домислюйте. Кожне повідомлення читайте й кодуйте окремо, власним судженням. **Не пишіть програм, скриптів чи регулярних виразів для кодування** — потрібне саме людське (змістове) прочитання кожного тексту.

Посилання в тексті показано так: `підпис [https://адреса]`.

## 1. Канали і самопосилання

Самопосилання каналу (його назва, бот, хендл, «підписуйтесь на нас», підпис-футер каналу) — **не джерело**.

| channel | як себе називає |
|---|---|
| truexanewsua | «Труха⚡️Україна», «Труха» |
| kievinfo_kyiv | «Киев Инфо / Київ Інфо», novosty_kiev |
| UaOnlii | «Україна Online / Украина Online» |
| vanek_nikolaev | «Ванёк / Ванєк Николаев» |
| lachentyt | «Лачен пише» |
| times_ukraina | «Times of Ukraine», «Радар Times» |
| batalionmonako | «Батальйон Монако», «Оперативний моніторинг» |

## 2. Що таке джерело

**Джерело** — це те, на що адміністратор **явно вказує як на походження інформації**.

| Джерело є | Джерела немає |
|---|---|
| «…, — УП», «— Зеленський», «— монітори» (підпис через тире) | «Зеленський прибув до Парижа» |
| «Зеленський заявив / повідомив / каже / пояснив…» | «СБУ затримала агента» — дія, а не повідомлення |
| «у Генштабі повідомили», «йдеться у матеріалі NYT» | учасник події, згаданий у новині |
| «за даними / за словами / з посиланням на / як пише / джерело: Х» | донати, реклама, магазини |
| «Генштаб: …» — двокрапка після назви актора | заголовок-тема з двокрапкою («Альфа-Банк: в чьих интересах…») |
| «СБУ повідомила про затримання», «за даними СБУ», «СБУ: затримано агента» | |
| «#нампишуть», «місцеві кажуть», «в мережі з'явилося відео» | |
| «Повідомляють, що…» (безособово) → анонімне джерело | «В Волновахе … сообщают» — місце, а не джерело |
| **виробник поширюваного контенту**: «відео зробили хлопці з каналу БАЗА» → канал БАЗА; «відео зняли місцеві» → очевидці | |
| посилання на медіа, офіційний сайт або конкретний Telegram-канал, навіть якщо в тексті джерело не назване («Детальніше: [тут] [https://pravda.com.ua/…]» → Українська правда) | посилання **лише** на соцмережу чи «інший сайт» (YouTube, Instagram, Facebook, X, TikTok, петиція, магазин) без джерела, названого в тексті |

**Платформа — не джерело, якщо названо автора:** «Єрмак написав у Facebook» → джерело Єрмак; «— Twitter сейму» → джерело Сейм. Лише «пишуть у Twitter» без автора → тип `social`.

**Та сама особа чи орган, названі двічі** («Спикер» і «Петр Андрющенко»; «Прем'єр Великобританії» і «Джонсон»), — **одне** джерело.

## 3. Рівень повідомлення

| Поле | Значення |
|---|---|
| `content_type` | `informational` — змістовне (новина, коментар, факт; навіть дуже коротке: «Усик переміг»); `alert` — оперативне оповіщення про загрозу (тривога, ракети, шахеди, «в укриття»); `technical` — без змісту: порожнє, лише емодзі, службове, **чисте самопромо чи реклама без іншої інформації** |
| `promotional` | `no` / `ad` (реклама товарів, послуг, інших каналів) / `self_promo` («підписуйтесь», «наш Instagram»). Незалежно від `content_type`: може бути `alert` + `self_promo`. **Посилання-запрошення в Telegram-канал усередині повідомлення (`t.me/+…` або `t.me/joinchat/…`), зокрема приховане під словом тексту, → `ad`** — незалежно від того, чи веде воно на інший канал, чи на сам канал; навіть якщо решта — змістовна новина (тоді `content_type` лишається `informational` / `alert`). Виняток — відкритий заклик підписатися на сам канал, де посилання прямо так і подано («Підписатися на …», «наш канал») → `self_promo` |
| `has_explicit_source` | `true` / `false` — чи є хоч одне джерело за правилами розділу 2 |
| `attribution_method` | `textual` (джерело назване в тексті) / `hyperlink` (видно лише з посилання на медіа / офіційний сайт / Telegram-канал) / `both` (назване в тексті **і** є посилання на медіа / офіційний сайт / канал) / `none` |
| `n_direct_sources` | кількість різних **прямих** джерел |
| `has_nested_source` | `true`, якщо є «джерело джерела» («CBS News із посиланням на американських чиновників») |

## 4. Джерела (`sources`) — кожне окремо

- `name` — як у тексті, повністю: «Мариупольский горсовет», «советник мэра Мариуполя Петр Андрющенко».
- `type`:

| type | що | приклади |
|---|---|---|
| `ua_media` | українські медіа | Суспільне, УП, ТСН, NV, Новини.LIVE |
| `foreign_media` | закордонні медіа | Reuters, CBS News, Yle |
| `russian_media` | російські медіа | ТАСС, Mash |
| `ua_official` | укр. влада, військові, держкомпанії, посадовці | Генштаб, ОВА, Подоляк, Верховна Рада |
| `foreign_official` | іноземні уряди, посадовці, міжнародні організації | Пентагон, прем'єр Великобританії, НАТО |
| `russian_official` | російська влада | Пєсков, МИД России |
| `politician` | депутати, партії, колишні посадовці | нардеп Железняк, «Європейська солідарність» |
| `expert` | експерти, аналітичні центри | Жданов, ISW |
| `company_organization` | компанії, фонди, ГО, наукові установи | ДТЕК, Autoconsulting, інститут |
| `telegram` | інші Telegram-канали | «монітори», @handle, DeepState |
| `social` | соцмережі як джерело (без автора) | «в мережі з'явилося відео», «пишуть у Twitter» |
| `unnamed_media` | медіа без назви | «ЗМІ», «росЗМІ», «видання» |
| `eyewitness` | очевидці, мешканці, підписники | «#нампишуть», «місцеві» |
| `anonymous` | анонімні | «джерела», «співрозмовник», «повідомляють» |
| `person_other` | названа особа, тип якої неясний з тексту | «Зять Шойгу», «Олексій Громов» |
| `other` | інше | документи («законопроєкт»), неясні абревіатури |

- `specificity`: `named` (конкретна назва чи особа) / `generic` (категорія чи лише посада: «ЗМІ», «монітори», «міністр») / `anonymous`.
- `level`: `direct` — на кого посилається сам канал; `embedded` — на кого посилається це джерело («із посиланням на…»); `intermediary` — видання, через яке передано слова актора. «— Радіо Свобода із посиланням на супутникові знімки» → Радіо Свобода `direct`, знімки `embedded`. «— український чиновник в коментарі The Economist на правах анонімності» → чиновник `direct` (`anonymous`), The Economist `intermediary`.
- `method`: `text` — назване в тексті; `link` — у тексті не назване, видно лише з посилання.

## 5. Посилання (`destinations`)

Для кожного посилання в тексті, крім донатів, реклами і самопосилань каналу:

- `domain` — домен (напр. `nv.ua`, `t.me/deepstateua`);
- `platform_type`: `ua_media_site`, `foreign_media_site`, `russian_media_site`, `official_site` (укр. держсайти), `foreign_official_site`, `social_platform`, `telegram_channel`, `other_site`;
- `relation`: `same_actor` («— Reuters» + reuters.com) / `intermediary` («— The Washington Post» + nv.ua) / `platform_hosting_actor` («— ОК «Південь»» + facebook.com) / `unrelated` / `unclear`.

## 6. Формат відповіді

Для кожного повідомлення — **один рядок JSON** (JSON Lines), без пропусків і в тому самому порядку, що й у пакеті. Нічого, крім цих рядків, не пишіть.

```
{"item_id":"V0001","content_type":"informational","promotional":"no","has_explicit_source":true,"attribution_method":"textual","n_direct_sources":1,"has_nested_source":true,"sources":[{"name":"CBS News","type":"foreign_media","specificity":"named","level":"direct","method":"text"},{"name":"американські чиновники","type":"anonymous","specificity":"anonymous","level":"embedded","method":"text"}],"destinations":[],"comment":""}
{"item_id":"V0002","content_type":"alert","promotional":"no","has_explicit_source":false,"attribution_method":"none","n_direct_sources":0,"has_nested_source":false,"sources":[],"destinations":[],"comment":""}
```

`comment` — лише якщо випадок справді сумнівний (коротко, чому).
