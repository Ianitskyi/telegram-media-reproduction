# Кодувальна інструкція: ручна перевірка (вибірка v1)

Файли:
- `sample_v1_blind.csv` — для кодувальника: **без** відповідей детектора (кодувати тільки його);
- `sample_v1.csv` — повна версія з результатами детектора (для підрахунку метрик після кодування).

1 122 повідомлення = 7 немедійних каналів × 3 періоди (до 24.02.2022 / 24.02.2022–2023 / 2024–21.04.2026) × (40 випадкових + до 20 позитивних за детектором). Seed: 20261023.

## Питання для кожного повідомлення

**Q1_names_prof_media** — чи повідомлення явно посилається на професійне медіа або називає його? (`так` / `ні`)
- рахується: посилання на сайт медіа; назва медіа як джерела («— УП», «пише Суспільне», «за даними Укрінформу»); згадка медіа як учасника події;
- **будь-яке** професійне медіа, не лише зі списку (ТСН, УНІАН, NV, Reuters теж — «так»);
- не рахується: офіційні джерела (Генштаб, ОВА, МВС, Президент), інші Telegram-канали, блогери, соцмережі.

**Q1_which_media** — які медіа (через `;`).

**Q2_attribution_type** — `посилання` / `атрибуція` (медіа названо як джерело інформації) / `згадка` (медіа згадано, але не як джерело) / `немає`.

**Q3_reproduces_content** — чи схоже, що зміст узято з матеріалу професійного медіа, навіть без атрибуції? (`так` / `ні` / `неясно`). Необов'язкове, суб'єктивне; потрібне для оцінки того, скільки відтворення «невидиме» для детекторів.

**fp_reason** — якщо детектор сказав «так», а ви «ні»: коротко чому.

**coder** — хто кодував (`Andrii`, `Claude`, `ChatGPT`, ...).

## Метрики (рахуються після кодування)
precision, recall, F1, частка хибних позитивів/негативів, Cohen's κ між кодувальниками; окремо за каналом, періодом, типом шаблону (safe / cs / ctx).
Поріг прийняття детектора — точність ≈ 0,90 (пропозиція ChatGPT; ⚑ потребує затвердження Андрієм).
