# Кодбук ручної валідації: явна атрибуція джерела (v3.2)

**Мета.** Перевірити, наскільки точно алгоритм (`src/v3/attribution.py`) визначає, чи названо джерело інформації в Telegram-повідомленні, яке це джерело і що за повідомлення. Лише після цієї перевірки алгоритм запускаємо на повному корпусі.
Структура кодбука запропонована ChatGPT (2026-10-24); правила — `docs/ATTRIBUTION_RULES.md`.

## 1. Файли

| Файл | Для кого |
|---|---|
| `validation/v3_validation_coding.xlsx` | **кодери**: аркуш «Кодування» (жовті колонки заповнювати; випадаючі списки), аркуш «Довідка» |

| `src/v3/validation_score.py` | рахує метрики й рішення go/no-go після кодування |

## 2. Вибірка (1 495 повідомлень)

- **A — випадкова, 1 045:** 19 страт (7 каналів × 3 періоди; двох каналів до 24.02.2022 не було) × 55. На ній рахуємо повноту (recall), реальну частку помилок і саму частку повідомлень з атрибуцією.
- **B — позитивні за прогнозом, 450:** 150 з текстовою атрибуцією, 150 з гіперпосиланням, 150 з «обома способами» або ≥2 джерелами. Потрібні, щоб стабільно оцінити точність (precision) для кожного механізму. Беруться з окремого випадкового пулу.
- Порядок перемішаний: кодер не знає, з якої частини повідомлення.
- **Подвійне кодування: 299 повідомлень** (колонка `double_coded` = «так»): 11 на страту з A + 30 на механізм з B. Їх незалежно кодують дві людини; розбіжності потім узгоджують разом, і узгоджена версія стає «золотим стандартом».

## 3. Загальні правила

1. Кодуйте **лише те, що видно в тексті** повідомлення (включно з посиланнями в квадратних дужках). Не шукайте оригінал і не домислюйте.
2. **Джерело** — це те, на що адміністратор **явно вказує як на походження інформації**: «— УП», «Зеленський заявив», «за даними Reuters», «у Генштабі повідомили», «Генштаб: …», «#нампишуть», посилання на медіа / офіційний сайт / Telegram-канал.
3. **Не джерело:** учасник події («СБУ затримала агента», «Зеленський прибув»); посилання лише на соцмережу чи «інший сайт» (YouTube, Instagram, петиція, магазин) без названого в тексті джерела (рішення ⚑6); донати, реклама; самопосилання каналу, його боти, «підпишись»; повторювані підписи-футери каналу.
4. Якщо сумніваєтесь — оберіть найімовірніше і напишіть коментар.

## 4. Рівень повідомлення

| Колонка | Значення | Як кодувати |
|---|---|---|
| **M1_content_type** | `informational` | змістовне повідомлення: новина, коментар, факт, навіть дуже коротке («Усик переміг») |
| | `alert` | оперативне оповіщення про загрозу: тривога, ракети, шахеди, «в укриття» |
| | `technical` | без змісту: порожнє, лише емодзі, службове, **чисте самопромо/реклама без іншої інформації** |
| **M2_promotional** | `no` / `ad` / `self_promo` | окремо від M1. `ad` — реклама товарів/послуг/інших каналів; `self_promo` — «підписуйтесь», «наш Instagram». Повідомлення може бути `alert` + `self_promo` |
| **M3_has_explicit_source** | `yes` / `no` | чи є хоч одне явне джерело (текстом або посиланням на медіа / офіційний сайт / Telegram-канал) |
| **M4_attribution_method** | `textual` / `hyperlink` / `both` / `none` | `hyperlink` — джерело видно лише з посилання; `both` — назване в тексті і є посилання на медіа/офіційний сайт/канал |
| **M5_n_direct_sources** | число | скільки різних **прямих** джерел (див. рівень нижче). Та сама особа/орган, названі двічі («Спикер» і «Андрющенко»), — одне джерело |
| **M6_has_nested_source** | `yes` / `no` | чи є «джерело джерела»: «CBS News із посиланням на американських чиновників» |

## 5. Рівень джерела (колонка SOURCES)

Кожне джерело — **окремий рядок** у клітинці (Alt+Enter; у Google Sheets — Ctrl+Enter), поля через «;»:

`назва; тип; конкретність; рівень; спосіб`

- **назва** — як у тексті, повністю: «Мариупольский горсовет», «советник мэра Мариуполя Петр Андрющенко».
- **тип** (S2):

| Тип | Що | Приклади |
|---|---|---|
| `ua_media` | українські медіа | Суспільне, УП, ТСН, NV, Новини.LIVE |
| `foreign_media` | закордонні медіа | Reuters, CBS News, Yle |
| `russian_media` | російські медіа | ТАСС, Mash |
| `ua_official` | укр. влада, військові, держкомпанії, посадовці | Генштаб, ОВА, Подоляк, Верховна Рада |
| `foreign_official` | іноземні уряди, посадовці, міжнародні організації | Пентагон, прем'єр Великобританії, НАТО |
| `russian_official` | російська влада | Пєсков, МИД России |
| `politician` | депутати, партії, колишні посадовці | нардеп Железняк, «Європейська солідарність» |
| `expert` | експерти, аналітичні центри | Жданов, ISW |
| `company_organization` | компанії, фонди, ГО, наукові установи | ДТЕК, Autoconsulting, інститут |
| `telegram` | інші Telegram-канали | «монітори», @handle, DeepState |
| `social` | соцмережі як джерело | «в мережі з'явилося відео», «пише у Twitter» |
| `unnamed_media` | медіа без назви | «ЗМІ», «росЗМІ», «видання» |
| `eyewitness` | очевидці, мешканці, підписники | «#нампишуть», «місцеві» |
| `anonymous` | анонімні | «джерела», «співрозмовник», «повідомляють» |
| `person_other` | названа особа, тип якої неясний з тексту | «Зять Шойгу», «Олексій Громов» |
| `other` | інше | документи («законопроєкт»), неясні абревіатури |

- **конкретність** (S3): `named` (конкретна назва/особа) / `generic` (категорія чи лише посада: «ЗМІ», «монітори», «міністр») / `anonymous`.
- **рівень** (S4): `direct` — на кого посилається сам канал; `embedded` — на кого посилається це джерело («із посиланням на…»). Приклад: «— Радіо Свобода із посиланням на супутникові знімки» → Радіо Свобода `direct`, супутникові знімки `embedded`.
- **спосіб** (S6): `text` — назване в тексті; `link` — у тексті не назване, видно лише з посилання (напр. «Детальніше: [тут](pravda.com.ua/…)» → Українська правда; link).

Приклад клітинки:
```
CBS News; foreign_media; named; direct; text
американські чиновники; anonymous; anonymous; embedded; text
```

**S5 extraction_quality** (exact / partial-but-correct / incorrect span) кодер **не** заповнює: її ставлять під час звірки з прогнозом алгоритму (етап 7).

## 6. Пункти призначення посилань (колонка DESTINATIONS)

Для кожного посилання в тексті (крім донатів, реклами, самопосилань) — рядок: `домен; тип платформи; відношення`

- **тип платформи** (D1): `ua_media_site`, `foreign_media_site`, `russian_media_site`, `official_site`, `foreign_official_site`, `social_platform`, `telegram_channel`, `other_site`.
- **відношення до джерела** (D3): `same_actor` (те саме, що й джерело: «— Reuters» + reuters.com) / `intermediary` (посередник: «— The Washington Post» + nv.ua) / `platform_hosting_actor` (майданчик джерела: «— ОК «Південь»» + facebook.com) / `unrelated` (додаткове, не пов'язане) / `unclear`.

## 7. Процедура

1. **Навчання (≈1 година):** обидва кодери разом кодують 20 повідомлень з `docs/ATTRIBUTION_EXAMPLES.md` і звіряють розуміння.
2. **Незалежне кодування:** кодер 1 — усі 1 495; кодер 2 — лише 299 рядків `double_coded` = «так». Не радитися.
3. **Узгодження:** розбіжності в 299 рядках обговорюють; узгоджене значення записують у файл кодера 1 (він стає «золотим стандартом»).
4. **Розрахунок:** `python -m src.v3.validation_score coder1.xlsx coder2.xlsx` → `results/v3/VALIDATION.md`.
5. **Звірка помилок:** Claude розбирає всі розбіжності алгоритму з «золотом» за класами (включно з S5), виправляє правила лише за класами помилок (не підганяючи під окремі приклади) і перевіряє на **новій** контрольній вибірці.

## 8. Пороги go/no-go (запропонував ChatGPT; затверджує Андрій)

| Показник | Поріг |
|---|---|
| `has_explicit_source`: precision / recall | ≥ 0,95 / ≥ 0,90 |
| виділення джерел-акторів: precision / recall | ≥ 0,90 / ≥ 0,90 |
| тип джерела: macro-F1 (великі класи ≥ 0,90) | ≥ 0,85 |
| включення в знаменник: accuracy; повнота змістовних | ≥ 0,95; ≥ 0,98 |
| тип пункту призначення: accuracy | ≥ 0,95 |
| міжкодерна надійність (κ) для ключових змінних | ≥ 0,80 |

Рідкісні класи (мало прикладів) окремо не оцінюються — у звіті їх об'єднують або позначають як пошукові.

## 9. Обсяг роботи

Орієнтовно 30–60 секунд на повідомлення без джерела і 1,5–3 хвилини з джерелами: кодер 1 — ≈25–35 годин, кодер 2 — ≈6–8 годин.
